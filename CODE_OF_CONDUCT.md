# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, in full and
without modification.

- Read it here: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain-text version: <https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt>
- FAQ: <https://www.contributor-covenant.org/faq/>
- Translations: <https://www.contributor-covenant.org/translations/>

It applies in every project space — issues, pull requests, discussions, commit
messages and code review — and whenever someone is representing the project in
public.

## Reporting

Report a violation privately by opening a
[security advisory](https://github.com/navid-kianfar/storage-io/security/advisories/new),
which is the one reporting channel here that is not public. Reports are handled
by the maintainers, who will keep the reporter's identity confidential and
respond using the Covenant's enforcement guidelines (correction, warning,
temporary ban, permanent ban).

A maintainer who is the subject of a report does not take part in deciding it.
